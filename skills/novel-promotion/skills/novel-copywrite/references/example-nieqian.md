# 示例：完整版推文文案（男频 / 穿书反派类）

这是用户亲自撰写的标准范例，展示完整版文案的写法。来源：番茄榜单 #1《穿书反派，把阴湿女主养成病娇了》第 1-3 章。

## 结构分析

第一段 = **钩子段**（~150 字），把核心冲突高度浓缩，最后用"..."留扣。后续段落按章节顺序展开，节奏紧凑。

## 完整版文案

我握着剪刀站在阴暗巷子里，面前是个嘴角带淤青、骨瘦嶙峋的少女，她看我的眼神像淬了冰的刀子。我刚穿到这具身体里就反应过来——原主为讨好绿茶女反派要剪她头发，可她是京城第一豪门丢失多年的千金，以后会把原主关地下室折磨三个月再喂鱼。我把剪刀狠狠扔进水槽，对着身边的黑衣保镖说林小姐的话老子不听了，然后朝着那少女走过去，想给她递瓶水缓和下关系...

阴暗的巷子里，潮湿的霉味裹着尘土钻进鼻腔。我睁眼，面前站着个骨瘦嶙峋的少女——身为女主的夏柠柒，她嘴角带着淤青，脸色病态苍白，披肩发凌乱地贴在脸上，看向我的眼神里满是毫不掩饰的厌恶。我低头，手里竟攥着一把寒光闪闪的剪刀。

突然，一段记忆撞进脑海：我穿书了，穿进一本叫《京枝归根》的女频文里，成了同名龙套。原主为了讨好绿茶女反派林小小，处处刁难夏柠柒，可谁知道夏柠柒是京城第一豪门丢失多年的千金？等她认亲后，原主被她折磨三个月，最后扔去喂鱼……那些满清十大酷刑的描写让我脊背发凉，连打针都怕的我，怎么受得了这个？

"少爷？你不是要剪她的头发吗？怎么发呆了？"身边的黑衣保镖挥挥手，打断我的思绪。哦对，现在正是原主被林小小教唆来剪夏柠柒头发的节点。剪个屁！这不是找死吗？我一把将剪刀扔进旁边的水槽，"剪什么剪？她头发那么漂亮，我疯了才剪！"

保镖们面面相觑："可这是林小姐的要求啊……"林小小？那个把原主当枪使的绿茶？我嗤笑："林小小是谁？我凭什么听她的？"这话一出，保镖们震惊得瞪圆了眼，连缩在墙角的夏柠柒都眉睫微动——原主是林小小舔狗的事，京城大学谁不知道？上次林小小生日，原主还送了百万保时捷呢。

"可是少爷你不是喜欢林小姐吗？"保镖还在多嘴。我冷声道："现在不喜欢了，再多嘴我割了你的舌头。"保镖立刻闭嘴，低头不敢再说话。我转向夏柠柒——这位可是我的保命符啊！她以后的态度直接决定我能不能活。我尽量放软语气："你饿吗？我带你去吃东西？"

夏柠柒眉头微凝，重度的眼袋让她看起来有种破碎的阴湿感，她只吐出一个字："滚。"我心里骂原主：看看你留的烂摊子！她对我的好感度估计是负一百吧？原主以前堵她、抢她饭、造她黄谣，还把她辛苦赚来的奖学金转给林小小……换谁能不恨？

夏柠柒捡起地上的帆布包要走，我急忙追上去："以前的事是我不对，给我个悔改的机会行吗？"她不理我，脚步更快，显然以为这是新的羞辱手段——原主以前总这样，给点希望再狠狠踩碎。我跟着她穿过巷子，到了一栋破烂旧公寓前——这也是原主害的，要不是他散布黄谣，夏柠柒也不会被宿舍排斥，只能租这种墙皮剥落的挂壁房。

她停下，捏紧拳头回头，指节泛白："你还有完没完？""我真没恶意……""你觉得我会信？"她眼底泛寒，声音里带着绝望，"有本事你进来强了我，反正活着也没意思，大不了同归于尽。"我心里一紧，原主到底把她逼成什么样了？我急忙摆手："我就站这儿不动……""恶心。"她咬着牙，拿出钥匙开门，"砰"地关上斑驳的铁门，震得墙上的灰簌簌往下掉。

我望着那扇紧闭的门，知道要挽回她的信任，还有很长的路要走。但至少，我现在没按原剧情作死，这是活下去的第一步。保镖小黑凑过来问："我们还要跟上去吗？"我抬手就给了他一个大逼斗，"跟你个头！"小黑捂着脸，眼里满是委屈却不敢多问。我托着下巴故作沉思："给你个任务——查夏柠柒住的旁边那间公寓有没有租出去，没人租的话立刻租下来，我明天就要住进去。"小黑应声答应，虽然他肯定好奇我放着大别墅不住要挤挂壁房，但有了刚才的教训，他没敢多嘴。其实我的目的很简单，就是想离夏柠柒近点，好刷好感度——毕竟我得在男主十一月出现前，把她对我的仇恨降到最低，不然这条命可能就没了。

正想着，手机响了，是特别关心提示音。拿起来一看，是林小小发来的消息："南哥哥，你答应我的事情做了吗？"呵，还想着让我剪夏柠柒的头发？我指尖飞快敲出一行字："滚远点，以后别联系了。"发送完直接把她拉黑。

另一边，林小小正和她的闺蜜唐柔做美甲，得意地说："祁南那只舔狗办事效率快，肯定已经把夏柠柒的头发剪下来了。"话音刚落手机就响了，她拿起一看，脸色瞬间煞白。唐柔凑过来问："怎么了？"林小小声音发颤："他让我别联系了……还把我拉黑了！"唐柔皱眉："不可能吧，早上他还邀你吃烛光晚餐呢。"林小小冷哼："我找他？主人会跟自家狗道歉吗？他饿了自然会回来。"两人没当回事，继续做美甲。

第二天我起得很早，镜子里的我头发凌乱但五官立体——这是原主为数不多的优点。洗漱完去厨房找秦姨，她是家里的阿姨，已经把我准备给夏柠柒的便当做好了，打开一看，小青龙、九节虾、海参样样俱全。

我提着便当到夏柠柒公寓门口，倚着护栏等她。五分钟后，她穿着缝补多次的白色连衣裙出来，揉着太阳穴——看来她昨晚熬夜剪视频了。我笑着打招呼："夏同学，我给你带早餐了。"她像没看见我似的，径直走过去。我追上去："你怕有毒我可以试吃！我真的是来赎罪的！"她冷冷瞥我一眼："滚远点。"我的笑容僵住，喉咙干涩——这和我以前玩的游戏不一样啊，她完全不给机会。

到了教室，夏柠柒找了个空位坐下，没吃早餐也没碰我的便当。我直接坐在她旁边，把便当推过去："姑奶奶你就吃吧，你不吃我怎么刷好感度啊？救人一命胜造七级浮屠，求你可怜可怜我当个好人吧！"周围的同学都投来怪异的目光——平时我都是给林小小送便当的，今天怎么换成夏柠柒了？难道又是整人的手段？我不管他们怎么看，只盯着夏柠柒，心里急得不行：我真的不想死啊……我攥着手里的三文鱼饭团便当，跟在夏柠柒身后换了三个位置，她终于忍无可忍回头，细眉拧成结："你到底要干嘛？"我把便当往前递了递，声音带着点委屈："想给你吃便当。"她冷冷吐出两个字："不吃。""可是你没买早餐，不饿吗？"她眼神骤冷，咬牙切齿："饿了，想扒你的皮，吃你的肉，喝你的血！"我后颈的青筋猛地跳了跳——书里的她确实干得出更血腥的事，不敢再招惹，却又放不下心。

戴着方框眼镜的秃顶授课老教授走进教室，讲的内容枯燥得让人犯困，我正打哈欠，听见他说要抽人回答问题，瞬间精神。"十七号同学。"我松了口气，我是二十号。身旁的夏柠柒却站了起来，教授问："置信区间是什么？"她声音清亮："在一定置信水平下，包含总体参数的取值范围。"教授点头让她坐下，她刚落座就晃了晃，薄唇泛白，额头冒了细汗——我作为医学生一眼就看出是低血糖。

我赶紧从便当里拿出饭团，递到她嘴边："啊，张嘴。"她别过脸，指尖攥得发白。我急了，压低声音威胁："快吃，不然我去医院找你阿嬷的麻烦。"她身体一僵，指尖嵌入掌心，最终还是妥协，低头一口口把饭团吃了。我看见她眼底的惊讶——饭团里是橙黄色的三文鱼，她好像没吃过。

下课铃响，我继续夹起便当里的虾："把虾吃了，不然我在你衣服上画鬼脸。"又夹起和牛："还有这个，不然上课挠你痒痒。"她腮帮子鼓鼓的，吞咽速度赶不上我投喂的节奏。前排的前校花女友林小小环着胸，嘴角撇着，身旁的林小小的闺蜜唐柔张大嘴："今天的你是不是病了？和平时完全不一样！"唐柔转头对林小说："放学我去质问他！"林小说："随便他。"可我瞥见她攥紧了衣角，脸色不太好看。

周围同学议论纷纷："居然喂夏柠柒？平时不都是给林校花带饭吗？""夏柠柒不化妆也挺好看的，瘦点但底子好。"唐柔立刻回头："你们忘了？她私生活可不干净！"男生们都闭了嘴。

便当见了底，夏柠柒的脸色好了些，唇瓣也有了血色。她抬眼问："多少钱？"我愣了愣，指着自己："你问我？"她默认。我摇头："不要钱。"她眼底闪过一丝不解，别过脸不再说话。我叹了口气——看来我的威胁又让她更恨我了……
